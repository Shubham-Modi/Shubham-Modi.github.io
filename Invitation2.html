Free Cloud Database Guide for Your Wish Wall

How to Store Wishes Globally for Free

Since this website is a free static HTML file (hostable on GitHub Pages, Netlify, or Vercel for ₹0), the best 100% free database is Supabase (PostgreSQL) or Firebase Firestore. This code already includes a built-in Supabase REST API connector!

1. Supabase (Recommended ⭐)

500MB free Postgres DB, instant REST API, works directly from this HTML file. Built-in below!

2. Firebase Firestore

Google's free NoSQL DB (1GB free, 50k reads/day). Great real-time listeners.

3. Google Sheets (SheetDB)

Saves RSVPs & wishes directly into a Google Sheet so elders can view in Excel.

Step 1: Create a Free Project at Supabase.com & Run this SQL

Open the SQL Editor in your free Supabase dashboard and paste this snippet to create your table with public read/insert access:

create table wedding_wishes (
  id bigint generated by default as identity primary key,
  guest_name text not null,
  attending_status text not null,
  message text not null,
  created_at timestamp with time zone default timezone('utc'::text, now())
);
alter table wedding_wishes enable row level security;
create policy "Allow public read" on wedding_wishes for select using (true);
create policy "Allow public insert" on wedding_wishes for insert with check (true);
Step 2: Connect Your Supabase URL & Anon Key Right Here (Or in the Code)
Or hardcode `SUPABASE_URL` & `SUPABASE_ANON_KEY` in `index.html` before hosting!
